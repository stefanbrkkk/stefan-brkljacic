# Embedded font provenance

These six WOFF2 files are byte-for-byte extractions from the portfolio's existing
embedded Inter, Fraunces and JetBrains Mono font faces at commit `8a4c317`.
The numbered files retain the original order and Unicode subset ranges in
`styles/site.css`. No font substitution, conversion or new font download was made.

`../manifest.json` records each extracted file's original SHA256 and byte count.
The Open Font License notices in `licenses/` were obtained from the official
Google Fonts repository; `licenses/sources.json` records their source URLs and
SHA256 values. The notices accompany the original font files unchanged.
