# Dated viewport captures

The three JPEGs are direct Chromium screenshots of the current public
[Harmonije Panonije website](https://harmonije-panonije.vercel.app/), captured on
4 October 2026 at 1440×900, 768×1024 and 390×844 CSS-pixel viewport sizes,
device scale factor 1 and reduced motion. Browser screenshots use JPEG quality
82. They show the page as it rendered, without reconstructed or generated imagery.

`capture-manifest.json` records exact UTC capture times, source URL, viewport,
HTTP response status, source HTML SHA256, image SHA256, byte count and source
page title/heading. The site's inherited network proxy required the browser
capture context to ignore its certificate error. This is evidence of the
rendered response, not an independent certificate validation or physical-device
verification. The dated captures do not update automatically.
